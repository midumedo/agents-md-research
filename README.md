## 五份核心文档

| 文档 | 是什么 | 什么时候读 |
|---|---|---|
| `reports/AGENTS.md-最佳实践研究报告.md` | **规范层**：5 章推演 + N1–N7 规则 + 54 条来源 + 证据使用提示 | 要可审计的结论 |
| `workbuddy/AGENTS.md-会被执行的文档.md` | **叙事层**：文档冗余免费、指令冗余收费；三条定律 | 要一条能记住的线 |
| `samples/AGENTS.md` | 32 份样本的索引：厂商 / 团队 / 行数 / 别名 / 置信度 / 价值 | 核对样本 |
| `refs/README.md` | 17 篇论文按"能不能引用"分档 + 六关判据 | 核对证据 |
| `教训.md` | 这次踩的十个坑 + 13 条站得住的结论 | 复用方法 |

**两者冲突时以报告为准**——它带来源。文章负责让人记住，报告负责让人核对。

## 三条阅读路径

- **拿结论**：`workbuddy/AGENTS.md-会被执行的文档.md`（20 分钟）
- **核证据**：`refs/README.md` 的六关与分档 → `samples/AGENTS.md` 的样本表 → 需要时回 `refs/md/` 与 `samples/` 原文
- **复用方法**：`教训.md` 的十个坑 → `AGENTS.md` 的四问
