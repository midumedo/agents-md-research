## 一、先定标准：什么算"能引用"

一篇论文对写作者的价值，不等于它的质量，而是它的结论能否直接支撑你的句子。要同时过六关：

| 关卡 | 问什么 | 不过关的后果 |
|---|---|---|
| 构念 | 它测的是成功率、成本、还是遵守率？ | 把"成本上升"读成"效果变差" |
| 总体 | 12 个 Python 仓库的结论，能推到你的场景吗？ | 把特定生态的结论当普遍规律 |
| 噪声 | 效应量多大，等价界多宽，p 值多少？ | 把 p=0.21 的 +2.4% 说成"提升" |
| 可反驳 | 有没有别的设计得出不同结论？ | 选择性引用单篇 |
| 独立性 | 作者是否在推销自己提出的方法或工具？ | 把工具论文当现象论文 |
| **时效** | 它测的那个模型 / harness 版本，现在还活着吗？ | 把"上个世代的 agent"的行为当现状 |

**时效这一关最容易被忽略，也最致命。** AGENTS.md 研究测的是"某个模型在某个 harness 里的行为"，而这两样东西大约每半年换一代：

- `2601.20404`（2026-01）用的是 2025 年底的 Codex / Claude Code。今天的 harness 已经换了几轮，Claude Code 甚至开始直接读 `AGENTS.md` 作为 `CLAUDE.md` 的兜底——**实验条件本身已经不存在了**。
- `2602.11988`（2026-02）用的 Sonnet 4.5、GPT-5.2、Qwen3-30B-Coder。结论仍可引用，但要注明"那一代模型"。
- 2026-10 之后的三篇（`2610.30571`、`2610.31715`、`2611.04367`）才是当前 harness 的观测。

**经验值：这类论文的半衰期约 6 个月。** 超过半年，除非它讲的是机制（如"指令通道压过工具输出"），否则只能当历史。

按这六关，17 篇分三档。

## 五、"四篇论文互相矛盾"其实在缩水

分档之后再看原来的争议地图，会发现真正的分歧只剩一处。

| 表面上的分歧 | 分档后的解释 |
|---|---|
| 有效率 vs 没效率 | 测的不是一个东西：成功率（`2602.11988`、`2607.27250`）vs 运行时间与 token（`2601.20404`）。而且后者是观察性关联 |
| 有用 vs 没用 | 受控的两篇（`2602.11988`、`2607.27250`）方向一致：**无可测的正确性提升**，成本上升 |
| 该长 vs 该短 | `2602.11988` 附录 B 实测：长度与成功率、成本都无显著相关。"越短越好"来自预算推理（HumanLayer），不是实验结论 |
| 该写什么 | 只剩描述性证据（`2610.31715`、`2511.12884`、`2606.15828`），它们能告诉你"大家在写什么"，不能告诉你"写了有没有用" |

**真正还没解决的分歧只有一个**：在文档贫瘠或冷门生态里，结论会不会反转？`2602.11988` 附录 B 给出一个线索——把仓库里所有文档删掉之后，同一批 LLM 生成文件反而 +2.7%，超过人写文件。作者也在局限性里承认语言生态可能影响结论。

这不是"两派吵架"，是"同一个问题的不同切片，最后一片还没人测"。

## 七、三条阅读路径

- **要形成判断**：`2602.11988`（受控、有成本数据）→ `2607.27250`（等价检验，界很宽）→ `2610.30571`（机制：为什么它会被无条件执行）。三篇读完，能自己判断剩下的是不是噪音。
- **要写一份文件**：HumanLayer（预算与渐进披露）→ `2606.15828`（坏味道清单，当检查表用）→ `2611.04367`（措辞）→ `2610.31715`（74% 无理由，提醒自己写理由）。
- **要做研究**：`2610.31715`（普查的框架与标注方法）→ `2511.12884`（维护模式）→ `2602.11988` 与 `2607.27250` 两套相反设计 → 最后看 `2610.32578`，学它的台账方法，别引用它的结论。
